# Collect Naukri jobs without code

1. Open [Naukri Jobs Scraper](https://apify.com/datascraperes/naukri-jobs-scraper?fpr=edudata).
2. In **Input**, add a **Job searches** entry, such as software engineer in Bengaluru.
3. Set **Maximum unique jobs** to 5 for a small first collection.
4. Keep both detail options enabled when descriptions and company information matter.
5. Click **Start** and follow progress.
6. Open **Dataset** and export JSON, CSV or Excel.

You need an Apify account; no Naukri login is required. Check the run summary and detail status as well as available rows. A successful platform run can still have partial coverage. If the source broadens a search, review its keyword and location.
